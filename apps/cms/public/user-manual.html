คู่มือโค้ช

ใช้ CMS + Courtside ช่วยปรับปรุงทีมเรา — ไม่ต้องจัดการทีมคู่แข่งในระบบ

ภาพรวมสั้นๆ
ส่วน ใช้ทำอะไร
CMS (เว็บ) หลังล็อกอินเข้าหน้า เริ่มต้น → จัดการผู้เล่น แมตช์ รายชื่อลงแข่ง และดูรายงานโค้ช
Courtside (แอป) บันทึกสถิติข้างสนาม (ช็อต ฟาล์ว เปลี่ยนตัว ฯลฯ) แล้วซิงก์ขึ้นเซิร์ฟเวอร์

1) หลังล็อกอิน — ทำตามลำดับ

  1. ผู้เล่น — เพิ่มรายชื่อทีมเรา (ชื่อ + เบอร์)
  2. แมตช์ — สร้างแมตช์โดยเลือกทีมเรา ใส่ชื่อคู่แข่งเป็นข้อความ เลือกเหย้า/เยือน แล้วกด จัดรายชื่อ
  3. ติ๊กคนที่ลงแข่งวันนี้ เลือกตัวจริง 5 คน — คนที่เหลือในรายชื่อ = ตัวสำรองในแอป
  4. เปิด Courtside → เลือกแมตช์ → ตรวจ 5 คนบนสนาม → เริ่มบันทึก → กดซิงก์
  5. กลับ CMS → รายงาน ดูคำแนะนำโค้ช / box score / แผนภาพการยิง

2) สิ่งที่ระบบไม่บังคับ

  • ไม่ต้องสร้างทีมคู่แข่งในฐานข้อมูล — ใส่ชื่ออ้างอิงพอ
  • ไม่บันทึกสถิติรายคนของคู่แข่งในระยะนี้
  • หน้า บัญชีฤดูกาล เป็นตัวเลือกเสริม ไม่ใช่รายชื่อลงแข่งต่อแมตช์

3) Courtside — ปุ่มสำคัญ

ปุ่ม ความหมาย
คลิกสนาม บันทึกช็อตทีมเรา → เลือกเข้า/ไม่เข้า → ผู้เล่น
ฟาล์ว / ยิงโทษ / เปลี่ยนตัว เหตุการณ์หลักข้างสนาม (อื่นๆ: สตีล บล็อก รีบาวด์รับ)
ซิงก์ ส่งข้อมูลที่ค้างขึ้นเซิร์ฟเวอร์ (ออฟไลน์บันทึกต่อได้)
Ctrl+Z เลิกทำรายการล่าสุด

4) แก้ปัญหาเบื้องต้น

อาการ วิธีแก้
แอปไม่มีรายชื่อ ไป CMS จัดรายชื่อแมตช์ แล้วรีเฟรชใน Courtside (ต้องเคยออนไลน์อย่างน้อยครั้งหนึ่ง)
ซิงก์ไม่สำเร็จ เช็กเน็ตแล้วกดซิงก์ใหม่ — ข้อมูลในเครื่องยังอยู่
รายงานว่าง บันทึกใน Courtside แล้วซิงก์ก่อน เปิดรายงานแมตช์นั้นอีกครั้ง

ใน CMS หลังล็อกอิน ดูเมนู เริ่มต้น ได้ทุกเมื่อ หรือเปิดหน้านี้จากลิงก์คู่มือ
