คู่มือ CMS

บันทึกสถิติสองทีม · ใบสถิติ FIBA · ใช้คู่กับแอป Courtside

ภาพรวม
ส่วน ใช้ทำอะไร
CMS (เว็บ) หลังล็อกอินเข้าหน้า เริ่มต้น → ผู้เล่นทั้งสองทีม → แมตช์ + รายชื่อ → รายงานใบสถิติสองทีม
Courtside (แอป Windows) บันทึกสถิติข้างสนามทั้งเหย้าและเยือน แล้วซิงก์ / ส่งออก Excel–PDF

1) หลังล็อกอิน — ทำตามลำดับ

  1. ผู้เล่น — เพิ่มผู้เล่นของทั้งสองทีม (ทีมเราและคู่แข่ง) ให้มีชื่อ + เบอร์
  2. แมตช์ — เลือกทีมเรา + ทีมคู่แข่งจาก dropdown (ต้องเป็นทีมในระบบ · ไม่พิมพ์ชื่อเอง) · เลือกเหย้า/เยือน · กรอกโค้ช/กรรมการได้ถ้าต้องการ
  3. กด จัดรายชื่อ — สลับแท็บทีมเรา / คู่แข่ง ติ๊กคนลงแข่ง เลือกตัวจริงไม่เกิน 5 คนต่อทีม
  4. เปิด Courtside → เลือกแมตช์ → จัด 5 คนบนสนามทั้งสองฝั่ง → เริ่มบันทึก → กดซิงก์เมื่อมีเน็ต
  5. กลับ CMS → รายงาน → แท็บใบสถิตินัด ดูตารางสองทีม · ส่งออก Excel/PDF/PNG

2) Courtside สั้นๆ (ตอนลงคะแนน)

  • แตะสนาม → เข้า/ไม่เข้า → เลือกผู้เล่นจากกริด เหย้า / เยือน (สีแยกชัด)
  • ยิงเข้า → แอสซิสต์หรือกด “ไม่มี”
  • ยิงไม่เข้า → OREB / DREB / TO ในชีตเดียวกัน
  • ฟาล์ว → คนทำผิด → ชนิด → คนถูกฟาล์ว (FD) หรือข้าม
  • ไม่ต้องสลับฝั่งก่อนทุกช็อต — แตะเบอร์ฝั่งที่ทำแอคชันได้เลย

3) สิ่งที่ควรรู้

  • คู่แข่งต้องเป็นทีมในระบบ (dropdown) — เพิ่มทีม/ผู้เล่นก่อนถ้ายังไม่มี
  • รายงานหลัก = FIBA Box Score สองทีม (มี FD, +/-, EF เมื่อมีข้อมูล)
  • หน้า บัญชีฤดูกาล เป็นตัวเลือกเสริม ไม่แทนรายชื่อลงแข่งต่อแมตช์
  • นาฬิกาเกม / นาทีเล่น (Min) ยังไม่อยู่ในรอบนี้

4) แก้ปัญหาเบื้องต้น

อาการ วิธีแก้
สร้างแมตช์ไม่ได้ / ไม่มีคู่แข่งในรายการ เพิ่มทีมและผู้เล่นคู่แข่งในหน้าผู้เล่นก่อน
แอปไม่มีรายชื่อฝั่งใดฝั่งหนึ่ง ใน CMS จัดรายชื่อทั้งสองแท็บ แล้วรีเฟรชใน Courtside (เคยออนไลน์อย่างน้อยครั้งหนึ่ง)
ซิงก์ไม่สำเร็จ เช็กเน็ตแล้วกดซิงก์ใหม่ — ข้อมูลในเครื่องยังอยู่
รายงานว่าง บันทึกใน Courtside แล้วซิงก์ก่อน เปิดรายงานแมตช์นั้นอีกครั้ง

ใน CMS ดูเมนู เริ่มต้น ได้ทุกเมื่อ หรือเปิดหน้านี้จากลิงก์คู่มือ
