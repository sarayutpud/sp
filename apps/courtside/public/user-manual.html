คู่มือผู้ใช้งาน

ระบบบันทึกสถิติบาสเก็ตบอล Courtside + CMS

สองส่วนหลัก
ส่วน ใช้ทำอะไร
Courtside บันทึกสถิติข้างสนาม ด้วยการคลิกแผนที่สนาม
CMS ล็อกอิน จัดการ/ดูรายการเกม

CMS — เข้าสู่ระบบ

  1. เปิดหน้า CMS
  2. สมัครหรือเข้าสู่ระบบด้วยอีเมล/รหัสผ่าน
  3. หลังเข้าสู่ระบบ จะเห็นรายการเกม

Courtside — บันทึกช็อต

  1. คลิกตำแหน่งช็อตบนแผนที่สนาม
  2. ระบบบอกให้ว่าเป็น 2PT หรือ 3PT
  3. เลือก เข้า หรือ ไม่เข้า
  4. เลือกผู้เล่นบนสนาม
  5. ข้อมูลถูกเก็บในเครื่องทันที

ปุ่มสำคัญ

ปุ่ม ความหมาย
ซิงก์ ส่งข้อมูลที่ค้างขึ้นเซิร์ฟเวอร์
Ctrl+Z / เลิกทำ ยกเลิกรายการล่าสุด
ส่งออก Excel ได้ไฟล์รายงาน .xlsx
สำรองเกมนี้ ดาวน์โหลดไฟล์สำรอง JSON

ไม่มีเน็ตทำอย่างไร

บันทึกต่อได้ตามปกติ → สถานะจะขึ้นว่าค้างซิงก์ → พอเน็ตกลับมา กด ซิงก์

อาการ วิธีแก้
ซิงก์ไม่สำเร็จ เช็กเน็ตแล้วกดซิงก์ใหม่ ข้อมูลในเครื่องยังอยู่
ล็อกอินไม่ได้ ตรวจอีเมล/รหัส หรือสมัครใหม่
