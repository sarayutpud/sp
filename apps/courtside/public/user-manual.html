คู่มือ Courtside

ลงคะแนนสองทีมข้างสนาม — เลือกฝั่งตอนแตะเบอร์

0) ติดตั้งแอป

ดาวน์โหลดจาก CMS (ปุ่ม ดาวน์โหลดแอป) — โฟลเดอร์มีครบ Setup .exe · MSI · portable .exe

นำเข้าผู้เล่นจำนวนมาก / ล้างระบบทำใน CMS เท่านั้น — แอปนี้โฟกัสบันทึกข้างสนาม

1) ก่อนเริ่มเกม

  1. ใน CMS สร้างแมตช์ + จัดรายชื่อทั้งสองทีมแล้ว (หรือนำเข้า Excel ก่อน)
  2. เปิด Courtside → เลือกแมตช์
  3. เลือก 5 คนบนสนามทั้ง เหย้า และ เยือน
  4. กดเริ่มบันทึกสถิติ

2) ลงคะแนนอย่างไร (สำคัญ)

ไม่ต้องสลับทีมก่อนทุกช็อต — แตะสนาม แล้วเลือกผู้เล่นจากกริดสองสี

  1. แตะจุดบนสนาม (ระบบแยก 2PT / 3PT ให้)
  2. เลือก เข้า หรือ ไม่เข้า
  3. แตะเบอร์ฝั่งที่ยิง — สีเหย้า / สีเยือน
  4. ถ้าเข้า → แอสซิสต์หรือกด “ไม่มี”
  5. ถ้าไม่เข้า → เลือก OREB / DREB / TO

3) ปุ่มสำคัญ

ปุ่ม / คีย์ ความหมาย
คลิกสนาม บันทึกช็อต → เข้า/ไม่เข้า → เลือกคนทั้งสองทีม
ฟาล์ว (F) คนทำผิด → ชนิด → คนถูกฟาล์ว (FD) หรือข้าม
ยิงโทษ (T) / เปลี่ยนตัว (U) โทษของฝั่งที่เลือก · เปลี่ยนตัวใช้ฝั่งที่โฟกัสอยู่
สตีล / บล็อก / DREB / OREB เลือกคนจากกริดสองทีม (หรือฝั่งที่เกี่ยวกับแอคชัน)
แตะสกอร์บอร์ด / H · A โฟกัสทีม (ตะกร้า + เปลี่ยนตัว) — ไม่ล็อกว่าใครยิง
ซิงก์ ส่งข้อมูลค้างขึ้นเซิร์ฟเวอร์ (ออฟไลน์บันทึกต่อได้)
Excel / PDF ใบสถิติ FIBA สองทีม — PDF รองรับชื่อภาษาไทย
Ctrl+Z / Esc เลิกทำรายการล่าสุด / ปิดชีตเลือกคน

4) แก้ปัญหาเบื้องต้น

อาการ วิธีแก้
ไม่มีรายชื่อฝั่งใดฝั่งหนึ่ง ไป CMS จัดรายชื่อทั้งสองแท็บ แล้วรีเฟรชรายการแมตช์
ซิงก์ไม่สำเร็จ เช็กเน็ตแล้วกดซิงก์ใหม่ — ข้อมูลในเครื่องยังอยู่
สกอร์/สถิติผิดทีม ดูสีตอนเลือกเบอร์ · ใช้ Ctrl+Z แล้วบันทึกใหม่
หลัง CMS ล้างระบบแล้วยังเห็นแมตช์เก่า รีเฟรชรายการ / ล้างแคชแอป แล้วซิงก์ใหม่

จัดการทีม · นำเข้า Excel · รายงานเต็มรูปแบบทำใน CMS หลังล็อกอิน
คู่มือระบบเต็ม: ดูใน CMS หน้าเริ่มต้น หรือไฟล์ docs/USER_MANUAL.md
