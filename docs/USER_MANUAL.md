# คู่มือผู้ใช้งาน SP — ระบบสถิติบาสเก็ตบอล

แบรนด์: **SP FITNESS BANG SUE**  
รายงานหลัก: **FIBA Box Score สองทีม** (เหย้า + เยือน)

| ส่วน | ใช้ทำอะไร | เปิดอย่างไร |
|------|-----------|-------------|
| **CMS** | จัดการลีก/ทีม/ผู้เล่น/แมตช์ · นำเข้า Excel · รายงาน · ดาวน์โหลดแอป | เว็บ (เช่นพอร์ต 5173) |
| **Courtside** | บันทึกสถิติข้างสนามแบบออฟไลน์ได้ · ซิงก์ขึ้นคลาวด์ | แอป Windows (Setup / MSI / exe) |

บัญชีทดลอง (local seed): `sp@test.com` / `sptest`

---

## 1) ดาวน์โหลด Courtside (Windows)

ใน CMS กด **ดาวน์โหลดแอป** (หัวหน้าจอ) หรือเปิดจากหน้าคู่มือ — โฟลเดอร์ Google Drive มีครบ 3 ไฟล์:

| ไฟล์ | ใช้เมื่อ |
|------|----------|
| `SP-Courtside-Setup-*.exe` | ติดตั้งแบบ NSIS — **แนะนำผู้ใช้ทั่วไป** |
| `SP-Courtside-*.msi` | ติดตั้งแบบ MSI |
| `SP-Courtside.exe` | รันพกพา ไม่ต้องติดตั้ง |

หลังล้างข้อมูลใน CMS แล้วเคยซิงก์บนเครื่องมาก่อน — ให้รีเซ็ต/ล้างแคชใน Courtside หรือเลือกแมตช์ใหม่หลังซิงก์อีกครั้ง

---

## 2) ลำดับงานแนะนำ (CMS → Courtside → รายงาน)

1. **การแข่งขัน** — เพิ่มลีก/ทัวร์นาเมนต์  
2. **ทีม** — เพิ่มทีมเราและคู่แข่ง  
3. **ผู้เล่น** — เพิ่มชื่อ + เบอร์ทั้งสองทีม *หรือ* ใช้ **นำเข้า Excel**  
4. **แมตช์** — เลือกการแข่งขัน + ทีมเรา + คู่แข่ง · เหย้า/เยือน · **จัดรายชื่อ** ทั้งสองแท็บ (ตัวจริงไม่เกิน 5 คน/ทีม)  
5. **Courtside** — เลือกแมตช์ → ตั้ง 5 คนบนสนามทั้งฝั่ง → บันทึก → กดซิงก์เมื่อมีเน็ต  
6. **รายงาน** — ใบสถิติ FIBA · ประเมินผู้เล่น · โซนยิง · สรุปโค้ช · ฤดูกาล · แชร์ลิงก์  

---

## 3) หน้าใน CMS

| เมนู | ทำอะไร |
|------|--------|
| เริ่มต้น / คู่มือ | คู่มือในแอป (แนะนำเริ่มที่นี่) |
| การแข่งขัน | เพิ่ม/แก้/ลบลีกหรือทัวร์นาเมนต์ |
| ทีม | เพิ่ม/แก้/ลบทีม — ลบทีมจะลบผู้เล่นของทีมนั้นด้วย (ลบไม่ได้ถ้ายังมีแมตช์อ้างอิง) |
| ผู้เล่น | เลือกทีมแล้วเพิ่ม/แก้/ลบชื่อ + เบอร์ |
| นำเข้า Excel | อัปโหลด xlsx/csv คอลัมน์ **เบอร์ · ชื่อ · ทีม** · ดาวน์โหลดเทมเพลต · **ล้างระบบ** |
| แมตช์ | สร้าง/แก้แมตช์จากรายการ · จัดรายชื่อลงแข่ง · ลบแมตช์ทีละนัด |
| รายงาน | FIBA Box Score · ประเมินผู้เล่น · โซน · โค้ช · ฤดูกาล · แชร์ |
| บัญชีฤดูกาล | ตัวเลือกเสริม — ไม่แทนรายชื่อลงแข่งต่อแมตช์ |

CMS รองรับมือถือ (เมนูแฮมเบอร์เกอร์ · ปุ่มใหญ่ · พรีวิวนำเข้าแบบการ์ด)

### นำเข้า Excel / CSV

1. ดาวน์โหลดเทมเพลตจากหน้า **นำเข้า Excel**  
2. กรอกคอลัมน์: **เบอร์** | **ชื่อ** | **ทีม**  
3. เลือกไฟล์ → ตรวจพรีวิว → กดนำเข้า  
4. ระบบ **สร้างทีมใหม่** ถ้ายังไม่มี · **อัปเดตชื่อ** ถ้าทีม+เบอร์ซ้ำ  

### ล้างระบบ (อันตราย)

ที่หน้า **นำเข้า Excel** มีปุ่มล้างระบบ — ลบ **แมตช์ + ผู้เล่น + ทีม** ทั้งหมด (การแข่งขันยังอยู่)  
ต้องยืนยัน 2 ขั้น และพิมพ์คำว่า `ล้างระบบ`  
ใช้เมื่อต้องการเริ่มต้นข้อมูลใหม่ทั้งก้อน — ไม่ใช่การลบแค่แถวที่นำเข้า

## 4) บันทึกสถิติด้วย Courtside

### ก่อนเริ่ม
- ใน CMS จัดรายชื่อทั้งสองทีมแล้ว  
- เปิดแอป → เลือกแมตช์ → ตั้ง 5 คนบนสนามทั้งเหย้าและเยือน  
- ดูแถบสถานะ: ออนไลน์ / ออฟไลน์ / ค้างซิงก์  

### ลงคะแนนช็อต
1. แตะจุดบนสนาม (ระบบคำนวณ 2PT / 3PT ให้)  
2. เลือก **เข้า** หรือ **ไม่เข้า**  
3. เลือกผู้ยิงจากกริดสองสี (ไม่ต้องสลับทีมก่อนทุกช็อต)  
4. ถ้าเข้า → แอสซิสต์หรือ “ไม่มี” · ถ้าไม่เข้า → OREB / DREB / TO  

### ปุ่มที่ควรรู้

| ปุ่ม / คีย์ | ความหมาย |
|-------------|----------|
| ฟาล์ว (F) | คนทำผิด → ชนิด → คนถูกฟาล์ว (FD) หรือข้าม |
| ยิงโทษ (T) / เปลี่ยนตัว (U) | ตามฝั่งที่โฟกัส |
| AST / STL / BLK / DREB / OREB | เลือกคนจากกริด |
| แตะสกอร์บอร์ด / H · A | โฟกัสทีม (ตะกร้า + เปลี่ยนตัว) |
| ซิงก์ | ส่งข้อมูลค้างขึ้น Supabase |
| Excel / PDF | ใบสถิติ FIBA สองทีม (รองรับชื่อภาษาไทยใน PDF) |
| Ctrl+Z / Esc | เลิกทำ / ปิดชีต |

### ออฟไลน์
บันทึกได้ตามปกติ → พอมีเน็ตกด **ซิงก์** — ข้อมูลในเครื่องยังอยู่ถ้าซิงก์ล้มเหลว

## 5) รายงานและส่งออก

- **FIBA Box Score** — สองทีม (Excel / PDF) จาก CMS และ Courtside  
- **ประเมินผู้เล่น** · **โซนยิง** · **สรุปโค้ช** · **ฤดูกาล** — ใน CMS  
- **แชร์ลิงก์สาธารณะ** — `/share/:gameId` (อ่านอย่างเดียว)  
- PDF ฝังฟอนต์ **Sarabun** เพื่อแสดงภาษาไทยถูกต้อง  

---

## 6) ความหมายสีธีม SP

- **น้ำเงินเข้ม** — หัวข้อ / กรอบหลัก  
- **เหลือง** — ปุ่มสำคัญ / จุดเน้น  
- **แดง** — โลโก้ / คำเตือน  

---

## 7) แก้ปัญหาเบื้องต้น

| อาการ | ลองทำ |
|-------|--------|
| ไม่มีรายชื่อใน Courtside | จัดรายชื่อทั้งสองแท็บใน CMS แล้วรีเฟรชแอป |
| ซิงก์ไม่สำเร็จ | เช็กเน็ตแล้วกดซิงก์ใหม่ |
| ล็อกอิน CMS ไม่ได้ | ตรวจอีเมล/รหัส · หรือ seed `sp@test.com` / `sptest` |
| ลบทีมไม่ได้ | ยังมีแมตช์อ้างอิง — ลบแมตช์ก่อน หรือใช้ล้างระบบ |
| PDF ไทยเพี้ยน (เวอร์ชันเก่า) | อัปเดตแอป/CMS ให้ใช้ชุดที่มีฟอนต์ Sarabun |
| หลังล้างระบบแล้วยังเห็นข้อมูลเก่าในแอป | ล้างแคช Courtside / เลือกแมตช์ใหม่หลังซิงก์ |

## 8) สิทธิ์โดยย่อ

- **ผู้บันทึกสถิติ** — Courtside เป็นหลัก  
- **ผู้จัดการแข่งขัน** — CMS จัดลีก/ทีม/แมตช์/นำเข้า  
- **ผู้ชมรายงาน** — ดูผลและลิงก์แชร์ตามที่เปิดให้  

ติดต่อผู้ดูแลระบบของ SP FITNESS BANG SUE หากต้องการบัญชีเพิ่ม
