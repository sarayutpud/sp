# คู่มือผู้ใช้งาน SP — ระบบสถิติบาสเก็ตบอล

แบรนด์: **SP FITNESS BANG SUE**  
ระบบนี้มี 2 ส่วนหลักสำหรับผู้ใช้ทั่วไป

| ส่วน | ใช้ทำอะไร | เปิดอย่างไร |
|------|-----------|-------------|
| **Courtside** | บันทึกสถิติข้างสนาม (คลิกแผนที่สนาม) | แอป Windows หรือเว็บพอร์ต 1420 |
| **CMS** | จัดการทีม/เกม ดูรายการแข่ง ล็อกอิน | เว็บพอร์ต 5173 |

---

## 1) เริ่มต้นใช้งาน CMS (เว็บจัดการ)

1. เปิด CMS ในเบราว์เซอร์
2. **สมัคร** ด้วยอีเมล + รหัสผ่าน (อย่างน้อย 6 ตัว) หรือ **เข้าสู่ระบบ** ถ้ามีบัญชีแล้ว
3. หลังล็อกอิน จะเห็นรายการเกมในระบบ
4. ออกจากระบบได้ด้วยปุ่ม **ออกจากระบบ**

> ถ้าสมัครแล้วเข้าไม่ได้ อาจต้องยืนยันอีเมลตามการตั้งค่า Supabase Auth

---

## 2) บันทึกสถิติด้วย Courtside (ข้างสนาม)

### ก่อนเริ่มเกม
- ตรวจว่าเครื่องออนไลน์หรือพร้อมทำงานออฟไลน์
- ดูแถบสถานะมุมบน: **ออนไลน์ / ออฟไลน์ / ค้างซิงก์ N รายการ**
- (เวอร์ชันเต็ม) ตรวจ roster, starter 5 คน, ทิศตะกร้า — ตอนนี้มีโหมดสาธิตผู้เล่น 5 คน

### บันทึกช็อต (ขั้นตอนหลัก)
1. **คลิกบนแผนที่สนาม** ตรงตำแหน่งที่ผู้เล่นยิง  
2. ระบบคำนวณให้อัตโนมัติว่าเป็น **2PT หรือ 3PT**  
3. เลือก **เข้า** หรือ **ไม่เข้า**  
4. เลือก **ผู้เล่นบนสนาม** (เฉพาะ 5 คนที่ลงเล่น)  
5. ข้อมูลถูกบันทึกในเครื่องทันที (ไม่ต้องรอเน็ต)

### ปุ่มที่ควรรู้
| ปุ่ม / คีย์ | ความหมาย |
|-------------|----------|
| **ซิงก์** | ส่งข้อมูลที่ค้างในเครื่องขึ้นเซิร์ฟเวอร์ |
| **เลิกทำ (Ctrl+Z)** | ยกเลิกรายการล่าสุด |
| **ส่งออก Excel** | ได้ไฟล์ `.xlsx` (Box Score / PBP / Shots) |
| **สำรองเกมนี้** | ดาวน์โหลดไฟล์สำรอง JSON เก็บไว้ก่อนเครื่องพัง |

### ทำงานตอนไม่มีเน็ต
1. บันทึกช็อตได้ตามปกติ  
2. แถบสถานะจะขึ้นว่า **ค้างซิงก์**  
3. พอเน็ตกลับมา กด **ซิงก์** หนึ่งครั้ง  

---

## 3) ส่งออกและสำรองข้อมูล

- **Excel**: ใช้ส่งให้โค้ช/กรรมการหลังเกม  
- **Backup JSON**: สำรองฉุกเฉิน เก็บใน USB หรือโฟลเดอร์แชร์  

อย่าปิดเครื่องแรงๆ ขณะกำลังซิงก์จำนวนมาก — รอข้อความซิงก์สำเร็จก่อน

---

## 4) ความหมายสีธีม SP

- **น้ำเงินเข้ม** — หัวข้อ / กรอบหลัก / ความน่าเชื่อถือ  
- **เหลือง** — ปุ่มสำคัญ / จุดเน้น  
- **แดง** — โลโก้ SP / คำเตือน  

โลโก้กอริลลา SP FITNESS BANG SUE คือสัญลักษณ์แบรนด์ของระบบนี้

---

## 5) แก้ปัญหาเบื้องต้น

| อาการ | ลองทำ |
|-------|--------|
| API ไม่พร้อม | แจ้งแอดมินให้รันเซิร์ฟเวอร์ หรือเช็กเน็ต |
| ซิงก์ไม่สำเร็จ | เช็กเน็ต แล้วกดซิงก์ใหม่ — ข้อมูลในเครื่องยังอยู่ |
| ล็อกอินไม่ได้ | ตรวจอีเมล/รหัส หรือสมัครใหม่ |
| คลิกสนามแล้วไม่บันทึก | ต้องเลือก Made/Miss และผู้เล่นให้ครบ |

---

## 6) สิทธิ์และบทบาท (โดยย่อ)

- **ผู้บันทึกสถิติ (Statistician)** — ใช้ Courtside เป็นหลัก  
- **ผู้จัดการแข่งขัน** — ใช้ CMS จัดทีม/ตาราง  
- **ผู้ชม/รายงาน** — ดูผลและ export (ตามสิทธิ์ที่แอดมินให้)

หากต้องการบัญชีหรือสิทธิ์เพิ่ม ติดต่อผู้ดูแลระบบของ SP FITNESS BANG SUE
